特別区 建築構造「未出穴埋め100」

■ GitHub Pagesで更新する場合
1. リポジトリを開く
2. Add file → Upload files
3. このフォルダ内の以下5ファイルをアップロード
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
4. Commit changes

既に同名ファイルがある場合は、アップロードすると置き換え候補として扱われます。
GitHub Pages側のURLは原則そのままです。

・ホーム画面からセットを選択
